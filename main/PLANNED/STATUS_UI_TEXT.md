# [예정 항목] 상태창/UI 문구 규칙

## [명칭 변경]
- `파생 스텟`, `파생 스탯` → `전투 스탯`

## [박스 제목]
각 카드/박스 제목은 본문과 시각적으로 분리되도록 아래 형식을 권장합니다.
- `【기본 정보】`
- `【능력치】`
- `【전투 스탯】`
- `【장비】`
- `【기술】`
- `【특성】`
- `【상태 효과】`
- `【퀘스트】`
- `【동료】`

괄호는 장식용 둥근 괄호보다 `【 】`를 권장합니다. 한글 UI에서 제목 경계가 더 분명합니다.

## [기술/특성 상세 카드]
기술:
`[행동 유형] / [대상] / [공격 또는 내성] / [피해 또는 회복] / [지속] / [사용 제한]`

특성:
`[상시/반응] / [적용 조건] / [정확한 보정] / [적용되는 판정] / [사용 제한]`

모호한 문구 예:
- 금지: "공격이 더 강해진다."
- 권장: "명중 시 1d6 추가 피해. 자신의 턴마다 1회."

- 금지: "적을 제압한다."
- 권장: "대상은 STR 내성(DC 8 + 숙련 보너스 + WIS 수정치). 실패 시 다음 자신의 턴 종료까지 구속."
